# Real brand logos

Finora shows a coloured brand tile (Zomato red, Blinkit yellow, Uber black...) out of the box.
To show the **official logo image** instead, drop a file here named after the brand keyword:

    zomato.png   swiggy.svg   blinkit.png   uber.svg   amazon.png   netflix.svg ...

Allowed: .png .svg .webp .jpg. No code change and no restart needed, just refresh the page.
Keywords supported: zomato swiggy blinkit zepto instamart bigbasket uber ola rapido irctc amazon flipkart myntra nykaa meesho
netflix spotify hotstar youtube jio airtel phonepe paytm domino mcdonald starbucks kfc apple google
(add more in BRANDS inside static/app.js).

Get logos from each brand's official "brand assets / press kit" page. Logos are trademarks of their owners.
